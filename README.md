# GoldLabs Website Demos

Free website demos for local businesses.

Built by [GoldLabs.ai](https://goldlabs.ai)

## How it works

Each folder is a generated demo site, served via GitHub Pages at
[sites.goldlabs.ai](https://sites.goldlabs.ai). Sites are generated by
`generator/generate.js` from `generator/leads.json` — edit the templates in
`generator/`, never the site folders themselves.

The Base44 leadgen pipeline adds new sites by firing a `repository_dispatch`
event (see `.github/workflows/build-site.yml`).

## About

These are demo websites built to show local businesses what their online
presence could look like.
